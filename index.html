C++ 원형 큐 시뮬레이터

지금 과제 코드 방식 그대로: front == rear 이면 EMPTY, nextRear == front 이면 FULL. 실제 주문 최대 5개를 저장하려고 배열은 6칸을 씁니다.

front0
rear0
nextRear1
상태EMPTY
front = 다음에 serve할 주문rear = 다음 주문을 넣을 칸

왜 front와 rear가 겹치면 FULL이 아니야?

이 구현에서는 front == rear를 이미 “아무 주문도 없음”이라는 표시로 예약했어.

그래서 FULL도 똑같이 front == rear로 만들면 컴퓨터가 EMPTY인지 FULL인지 구분할 수 없어.

해결법은 배열을 한 칸 더 만들고 그 한 칸을 항상 비워두는 것이야. 그래서 rear의 다음 칸이 front이면 더 들어갈 수 없다고 판단해.

과제 코드

int nextRear = (rear + 1) % (maxNumOrder + 1); if (nextRear == front) { return 0; // FULL } orderQueue[rear] = newOrder; rear = nextRear; OrderCnt++;

핵심: rear는 “마지막 주문 위치”가 아니라 다음 주문을 넣을 위치로 쓰고 있어.
